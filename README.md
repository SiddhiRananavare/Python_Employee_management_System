# Python_Employee_management_System
A Python-based Employee Management System that allows users to add, view, search, update, and delete employee records using a command-line interface and JSON file storage.

### How It Works

The application displays a menu that allows users to select different employee management operations. Employee records are stored in a JSON file so that saved data can be loaded again when the application runs.

Each employee record can contain details such as an employee ID, name, department, and salary, depending on the fields implemented in the program.
